# Run Flow2Act on LIBERO (Simulation)

> This example trains **Flow2Act** on **LIBERO** and evaluates it on **LIBERO** and **LIBERO-Plus**.<br>
> We use **Xiaomi-Robotics-0** as the base model.

⭐ Use `Flow2Act-xm0/` as the root directory for all steps below.

```bash
cd ./Flow2Act-xm0  # If your terminal is currently in the parent directory
```

## 1. Environmental Setup

First, set up the policy environment, then create a separate environment for motion cache export.

### 1.1 Flow2Act Policy Environment

```bash
sudo apt-get install -y ffmpeg
conda create -n flow2act python=3.11 -y
conda activate flow2act
pip install packaging ninja
pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements/train.txt
pip install flash-attn==2.8.3.post1 --no-build-isolation
pip install -e . --no-deps
```

### 1.2 Preprocessing Environment (Track4World)

```bash
conda create -n flow2act-preprocess python=3.11 -y
conda activate flow2act-preprocess
pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements/preprocess.txt
```

## 2. Data and Checkpoint Preparation

Next, prepare the LIBERO training data and pretrained weights.

### 2.1 LIBERO Dataset

Download the LIBERO training data in LeRobot v2.1 format from [IPEC-COMMUNITY's LIBERO collection](https://huggingface.co/collections/IPEC-COMMUNITY/libero-benchmark-dataset). We jointly train on LIBERO-Spatial, LIBERO-Object, LIBERO-Goal, and LIBERO-10. Place these datasets under `data/libero_lerobot/` as shown below.

### 2.2 Pretrained Weights

Download the complete [XR0 Pretrain Base](https://huggingface.co/XiaomiRobotics/Xiaomi-Robotics-0-Pretrain/tree/main) checkpoint directory, [Track4World](https://huggingface.co/TencentARC/Track4World/tree/main) (`track4world_da3.pth`), [DA3 Nested](https://huggingface.co/depth-anything/DA3NESTED-GIANT-LARGE-1.1/tree/main) (`config.json` and `model.safetensors`), and [ConvNeXt Tiny](https://download.pytorch.org/models/convnext_tiny-983f1562.pth). Place these weights under `checkpoints/` following the directory structure below.

Our trained **Flow2Act-XM0** policy is available at [ShawnRicardo/Flow2Act-HF](https://huggingface.co/ShawnRicardo/Flow2Act-HF/tree/main/xm0) as `xm0/flow2act_xm0.ckpt`. See the inference section below to use the released checkpoint.

### 2.3 Directory Structure

Place the four LIBERO datasets under `data/libero_lerobot/` and the weights under `checkpoints/`:

```text
Flow2Act-xm0/
├── data/
│   └── libero_lerobot/
│       ├── libero_10_no_noops_1.0.0_lerobot/
│       ├── libero_goal_no_noops_1.0.0_lerobot/
│       ├── libero_object_no_noops_1.0.0_lerobot/
│       └── libero_spatial_no_noops_1.0.0_lerobot/
└── checkpoints/
    ├── Xiaomi-Robotics-0-Pretrain/
    ├── Track4World/
    │   ├── track4world_da3.pth
    │   ├── DA3NESTED-GIANT-LARGE-1.1/{config.json,model.safetensors}
    │   └── torchvision/convnext_tiny-983f1562.pth
    ├── da3_flow2act/                         # Generated by weight extraction
    └── Flow2Act/                 
        └── flow2act_xm0.ckpt             # Checkpoint prepared for inference
```

### 2.4 Weight Extraction and Motion Cache Export

With the files in place, extract the DA3 weights and export the motion cache:

```bash
conda activate flow2act-preprocess
python preprocess/extract_da3_weights_flow2act.py \
    --checkpoint checkpoints/Track4World/track4world_da3.pth \
    --output-dir checkpoints/da3_flow2act
bash preprocess/export_motion_flow2act.sh
```

## 3. Training

Once preparation is complete, run the following command to train jointly on all four LIBERO datasets:

```bash
conda activate flow2act
GLOBAL_BATCH_SIZE=256 GRAD_ACCUM=1 \
NNODES=1 NPROC_PER_NODE=8 CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 \
MAX_STEPS=30000 \
bash train_scripts/train_flow2act_libero.sh
```

## 4. Inference

Download our released [Flow2Act-XM0 checkpoint](https://huggingface.co/ShawnRicardo/Flow2Act-HF/resolve/main/xm0/flow2act_xm0.ckpt) to `checkpoints/Flow2Act/flow2act_xm0.ckpt`, then prepare it for the current code using the command below. This updates the checkpoint metadata without changing the model weights.

```bash
conda activate flow2act
python scripts/import_flow2act_artifacts.py checkpoint \
    --source checkpoints/Flow2Act/flow2act_xm0.ckpt \
    --output checkpoints/Flow2Act/policy_flow2act.ckpt
```

For checkpoints trained with this repository, place the checkpoint directly at `checkpoints/Flow2Act/policy_flow2act.ckpt`. Next, set up the simulator for the benchmark you want to evaluate. Both evaluation commands use eight GPUs and evaluate all four suites by default.

```bash
sudo apt-get install -y unzip libegl1 libgl1 libglvnd0 libmagickwand-dev
```

### LIBERO

First, clone LIBERO and install its simulator environment:

```bash
git clone https://github.com/Lifelong-Robot-Learning/LIBERO.git third_party/LIBERO
conda create -n flow2act-libero python=3.10 -y
conda run -n flow2act-libero pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
conda run -n flow2act-libero pip install -r requirements/libero.txt
conda run -n flow2act-libero pip install --no-deps -e third_party/LIBERO
```

Then switch back to the policy environment and start evaluation:

```bash
conda activate flow2act
BENCHMARKS=libero bash scripts/evaluate_flow2act.sh
```

### LIBERO-Plus

LIBERO-Plus uses a separate simulator environment. Clone its repository and install the dependencies:

```bash
git clone https://github.com/sylvestf/LIBERO-plus.git third_party/LIBERO-plus
conda create -n flow2act-plus python=3.10 -y
conda run -n flow2act-plus pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
conda run -n flow2act-plus pip install -r requirements/libero_plus.txt
conda run -n flow2act-plus pip install --no-deps -e third_party/LIBERO-plus
```

Before evaluation, prepare the scene [assets](https://huggingface.co/datasets/Sylvest/LIBERO-plus/tree/main) following the [LIBERO-Plus instructions](https://github.com/sylvestf/LIBERO-plus), then run:

```bash
conda activate flow2act
BENCHMARKS=libero_plus bash scripts/evaluate_flow2act.sh
```
